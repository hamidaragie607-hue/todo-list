# To-Do List (Daily Planner)

A Python program that helps you plan a balanced day and review it in the evening.

## What it does
- Asks for your name
- Lets you plan your day across six areas: Faith, Learning, Career, body, Off time, and Sleep
- Understands durations like `30m` or `1.5 hours`
- Checks that your day is not more than 24 hours, and warns if you sleep less than 8 hours
- Asks for a goal for the day, and checks in the evening whether you worked on it
- Gives an evening review with a score and a message
- Lists what you forgot today
- Saves each day to a file, with one entry per day
- Shows your last 5 days
## How to run
1. Install Python 3
2. Run `python todo_list.py`

The app creates a `days.json` file on your computer to remember your days.
