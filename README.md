# To-Do List (Daily Planner)

A Python program that helps you plan a balanced day and review it in the evening.

## What it does
- Asks for your name
- Lets you plan your day across six areas: Faith, Learning, Career, body, Off time, and Sleep
- Checks that your day is not more than 24 hours and warns if you sleep less than 8 hours
- Gives an evening review with a score and a message
- add duration like 30m
- it will remind you what you forgot in the day
- it asks you whats your goal in a day and reminds you back if you accomplish the goal or not
- it saves each days progress 

## How to run
1. Install Python 3
2. it creates days.json on your computer to remember your days
3. Run `python todo_list.py`
